# Preguntas de reflexion

1.  ¿Qué problema resuelve la encapsulación?
2.  ¿Cuál es la diferencia entre clase padre y clase hija?
3.  ¿Qué significa polimorfismo?
4.  ¿Qué ventaja tiene la abstracción?
5.  ¿En qué casos usarías herencia en un sistema real?

------------------------------------------------------------------------

# Respuestas

1. Con la encapsulacion lo que evitamos es que otras partes del programa modifiquen los datos de forma incorrecta.
2. La diferencia es que la clase hija es la que hereda los datos de la clase padre.
3. Que dependiendo de quien lo llame va a actuar de manera diferente.
4. La ventaja es que te simplifica mucho el codigo y ahorra tiempo.
5. En un sistema de Administración de un colegio, ferretería.
